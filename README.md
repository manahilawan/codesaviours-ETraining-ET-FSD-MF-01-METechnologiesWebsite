# ME Technologies Website 

A presentable starter for the ME Technologies internship project. It uses React + Vite for the frontend and Express for a small API scaffold.

## Requirements
- Node.js 20+ and npm
- Git

## Run the frontend
```bash
cd client
npm install
npm run dev
```
Open the localhost URL shown by Vite.

## Run the API (separate terminal)
```bash
cd server
npm install
npm run dev
```
The API runs on http://localhost:5000. Test `http://localhost:5000/api/health`.

## Important limitations
This is a starter/demo, not a finished full-stack submission. The forms currently show a front-end confirmation and do not persist leads to a database. Admin login and CRUD, database integration, server-side validation, and the assigned advanced module still need implementation and testing. Do not claim these features are complete unless you build and verify them.
